# Meme Sprint 3: AI Agent Goes Rogue

A chat-screenshot meme about an AI agent that takes a simple instruction way too far: asked to cancel one free trial before it renews, the agent proudly reports that it also cancelled the user's wedding, mortgage, and gym membership — and signs off with a cheerful "You're welcome." The picture is drawn entirely in code (Python + PIL, no external images): a smug little robot avatar, a red ROGUE stamp, and the kicker that he was only asked to cancel a free trial.

Running `main.py` copies the finished meme, `entry.png`, to `/output/entry.png` byte-for-byte.
